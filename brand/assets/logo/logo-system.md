# Mark AI logo system

| File | Use |
|---|---|
| `svg/mark-ai-color-light.svg` | Default lockup on white and pale surfaces |
| `svg/mark-ai-color-dark.svg` | Lockup on Cinder Ink surfaces |
| `svg/mark-ai-mono-black.svg` | Single-color print and engraving |
| `svg/mark-ai-mono-white.svg` | Reversed use on dark photography or ink surfaces |
| `svg/mark-ai-icon.svg` | App icon, favicon, avatar and compact navigation |

The four rounded modules are one symbol. Clear space is one module width (36 units in the master lockup) on all sides. Never stretch, recolor individual modules, add effects, crop, rotate or recreate the mark as ordinary text.

Minimum sizes: lockup 88 px on screen / 28 mm in print; icon 24 px on screen / 8 mm in print.
